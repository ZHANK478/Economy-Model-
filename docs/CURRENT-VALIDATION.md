Пример: средняя диверсифицированная страна, 180 месяцев, полный файл движка. Обычный JSON с отступами: 91,7 МиБ; компактный JSON: 47 МиБ; gzip: 12,4 МиБ. Полная история и диагностика сохранены. Автосохранение использует один проход JSON вместо вложенного строкового сохранения; старые записи читаются.
