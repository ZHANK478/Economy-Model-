# Экономическая лаборатория

Месячный макроэкономический симулятор вымышленной развивающейся страны. Игрок принимает решения от лица государства и центрального банка: ставки, налоги, закупки, инвестиции, трансферты, банковские нормативы, валютные интервенции и структурная политика.

Начало: январь 2026, 10 млн жителей, годовой ВВП $60 млрд / $6 000 на человека, инфляция 8%, безработица 9%, государственный долг 50% ВВП. Сырьевая и диверсифицированная структуры выбираются при создании эксперимента.

## Запуск

Не требуются API-ключи, серверная база данных или установка пакетов.

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Нужен современный браузер с ES-модулями. Открытие `index.html` через `file://` может блокировать модули — используйте HTTP.

```sh
npm test
npm run validate
npm run build
```

`npm run build` копирует приложение в `dist/` для статического хостинга. Основной исходный код находится в корне и `src/`, а не в сгенерированной папке. `.openai/hosting.json` связывает приватную опубликованную копию с Sites.

## Возможности

- 23 взаимосвязанных блока. Полная карта и формулы — в [документации модели](docs/MODEL.md).
- «Следующий месяц», ускорение на 3 и 12 месяцев.
- Графики и отдельные разделы производства, бюджета, банков, внешнего мира и населения.
- Сравнение A/B: прежняя и новая политика из идентичного состояния, одинаковые внешние шоки.
- Сохранение точки и возврат к ней; автосохранение в текущем браузере.
- Экспорт/импорт всего состояния JSON и скачивание временных рядов CSV. Подготовленные решения также сохраняются в файле.
- Планирование внешних шоков, воспроизводимая случайность, изменение основных поведенческих коэффициентов.
- Общий реальный/номинальный/долларовый ВВП, возрастная пирамида, рождения, смерти, рождаемость и продолжительность жизни.
- Здравоохранение и поддержка семей с фактическим финансированием и задержками.
- «Паспорт страны»: ВВП, зарплата, население, Джини, модельный ИЧР, бедность, образование и доли собственности.
- Десять групп домохозяйств, прогрессивность налога, доходное и имущественное распределение.
- Покупка и продажа государственных долей, национализация с компенсацией, рекапитализация, управление и дивиденды.
- Суверенный дефолт по неплатежу / потерям при обмене, просрочка, переговоры, потери кредиторов и история эпизодов.
- Полный помесячный журнал решений, коэффициентов, шоков, операций и заметок; воспроизведение эксперимента.
- Длинные истории сохраняются на устройстве через IndexedDB, с запасным localStorage. Полный JSON нужен для переноса и резервной копии.
- Отчёты основаны на расчётах; модель не вызывает языковую модель для определения экономических результатов.

## Научный статус

Это самостоятельная **условно откалиброванная исследовательская модель**, а не эконометрически оценённая модель конкретной страны и не реализация готовой модели МВФ. Бухгалтерские тождества проверяются автоматически. Поведенческие правила являются гипотезами, описанными в документации; их коэффициенты подлежат эмпирической оценке.

Версия **3.0** уточняет банковскую передачу ставки, валютный риск и отдельный баланс ЦБ; добавляет собственность, распределение, ИЧР, дефолт и журнал. [Проверка](docs/VALIDATION.md): 129 игр, 47400 месячных переходов, 10 стратегий по 30 лет в двух структурах, общие шоки, собственность, кризисы, чувствительность и четыре 50-летних прогона. 14 журналов точно воспроизвели конечные показатели. Непрофинансированные расходы не гарантируют улучшения услуг; высокая ставка не гарантирует достижения инфляционной цели.

Формулы статистики стандартны, но данные и поведенческие коэффициенты условные. ППС не измерен, ИЧР — модельная оценка, риск потери финансирования не оценён по базе дефолтов. Подробности — [статус коэффициентов](docs/PARAMETERS.md). Эксперименты 1.0 / 2.0 остаются отдельно и не продолжаются по изменённым формулам 3.0.

Синтетические 12 месяцев до старта нужны только для первых годовых индикаторов. После 12 ходов годовые показатели полностью используют симулированную историю.

## Структура

| Файл | Назначение |
| --- | --- |
| `src/engine.js` | Чистое расчётное ядро, месячный ход, учёт, сохранения, сравнение |
| `src/demography.js` | Возрастно-половые месячные когорты, рождения, смерти, миграция |
| `src/strategies.js` | Десять воспроизводимых стратегий для проверки |
| `scripts/validate.mjs` | Основные игры, повторы, чувствительность, отчёты JSON/CSV |
| `src/config.js` | Политика, коэффициенты, профили, отрасли, матрица затрат, 23 блока |
| `src/indicators.js` | Джини, доходы, богатство, образование, модельный ИЧР |
| `src/ownership.js` | Передача / выпуск долей, выплаты, размывание, риск изъятия |
| `src/sovereign.js` | Условный риск финансирования, неплатежи, реструктуризация, NPV |
| `src/journal.js` | Полные решения и внешние условия каждого месяца |
| `src/storage.js` | Длинные браузерные сохранения и запасное хранилище |
| `src/app.js` | Интерфейс, SVG-графики, локальные сохранения |
| `docs/MODEL.md` | Формулы, единицы, порядок месяца, ограничения и источники |
| `tests/engine.test.js` | Балансы, временной шаг, воспроизводимость, импульсы и кризисные прогоны |
| `tests/extensions.test.js` | Статистика, собственность, дефолт, ЦБ, журнал, 30-летние траектории |
| `tests/storage.test.js` | Успешность записи / ошибки хранилища; без настоящего браузера |
| `tests/ui.test.js` | Проверки шаблонов и обработчиков интерфейса без настоящего браузера |

Изменение технологии, валютного режима или переход к реальной стране требует переработки и повторной калибровки, а не переименования страны в интерфейсе.
