# Республика — Android

Отдельная ветка `mobile/android`. Автономное приложение для Android 8.0 и новее: HTML/JS игры входит в APK, сервер и интернет для игры не нужны. Нужен современный Android System WebView с поддержкой ES-модулей и верхнеуровневого await.

В мобильном интерфейсе четыре раздела закреплены снизу, бюджет и следующий месяц — сверху. Сохранения находятся внутри приложения и не синхронизируются с браузером. Для переноса партии: в браузере «Сохранить», в приложении «Открыть» и выбрать JSON. Экспорт JSON и CSV использует системное окно Android; разрешение на весь накопитель не запрашивается. Удаление приложения удаляет внутреннее сохранение — заранее экспортируйте партию.

## Скачать APK

GitHub → Actions → Android APK → последняя успешная сборка ветки → Artifacts → `republic-android-apk`. Распаковать ZIP и открыть `app-debug.apk` на телефоне. Это тестовая сборка, не публикация в Google Play. Для последующих тестовых обновлений ключ debug сохраняется в кэше CI. Если кэш истечёт, подпись может смениться. Первая ранее выданная сборка использовала другой ключ: перед обновлением экспортируйте сохранение; если Android отказывает в обновлении, переустановите и импортируйте файл.

## Локальная сборка

JDK 17, Android SDK 35, Gradle 8.11.1:

```sh
npm test
npm run build
gradle -p android :app:assembleDebug :app:lintDebug
```

APK: `android/app/build/outputs/apk/debug/app-debug.apk`. В Android Studio открыть папку `android`, выполнить сборку веб-части из корня перед сборкой приложения. Gradle использует `dist` как assets; копия движка не создаётся.

Используется AndroidX WebViewAssetLoader с локальным HTTPS origin; внешние ресурсы блокируются. Пользовательские HTTP/HTTPS ссылки открываются вне приложения. Файловый JS-мост доступен только встроенному содержимому. Разрешений на интернет, камеру, микрофон и геолокацию нет. Экономические механизмы идентичны браузерной версии; календарь 2000 — смена даты, не историческая перекалибровка.
